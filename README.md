# Balaho_8-Acacia-code-and-READ.md

## Description
The code finds and calculates the distance between 2 points based on the user's inputs about the 2 points

## How to Run
1. Open the program
2. Run the program
3. Enter the needed values

## Input Needed
1. Value of how far the 1st point is in the x axis
2. Value of how far the 1st point is in the y axis
3. Value of how far the 2nd point is in the x axis
4. Value of how far the 2nd point is in the y axis

## Sample Output
- Enter the x-coordinate of the first point: 2
- Enter the y-coordinate of the first point: 3
- Enter the x-coordinate of the second point: 4
- Enter the y-coordinate of the second point: 3
- The distance between the 2 points is 2.0
